# 分期开放健身指导的效果评估与续批审签

本项目围绕社区全民健身公共服务的本地分析资料。数据均为合成记录，文件字段与时间口径按各自数据文件表示。项目目录包含业务资料、分析软件包和基础数据检查。

## 环境与运行

需要 Python 3.11 或更新版本，无第三方运行依赖。进入项目目录后运行 `python -m unittest discover -s tests -v` 检查合成资料。分析包位于 `src/trial`，可从 Python 导入。输入资料位于 `data/`，CSV 使用 UTF-8 编码和首行字段名，策略资料采用 JSON。

## 数据约定

所有居民、机构、地点与活动均为虚构标识，时间以数据字段的本地日期表示。空字段表示该资料没有登记值，不应据此推断业务事实；具体数据口径以相应字段和 JSON 政策文件为准。资料用于离线分析，不含外部服务或凭据。
