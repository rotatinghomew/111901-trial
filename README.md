# 分期开放健身指导的效果评估与续批审签

本项目围绕社区全民健身公共服务的本地分析资料。数据均为合成记录，文件字段与时间口径按各自数据文件表示。项目目录包含业务资料、分析软件包和基础数据检查。

## 环境与运行

需要 Python 3.11 或更新版本，无第三方运行依赖。进入项目目录后运行 `python -m unittest discover -s tests -v` 检查合成资料与评估逻辑。分析包位于 `src/trial`，可从 Python 导入。输入资料位于 `data/`，CSV 使用 UTF-8 编码和首行字段名，策略资料采用 JSON。

生成审签材料（汇总口径，不含居民标识）：

```
PYTHONPATH=src python -m trial --data data
```

同时导出供项目组比对波次的居民级追溯表（可含居民标识，不随审签材料提交）：

```
PYTHONPATH=src python -m trial --data data --audit /tmp/audit.csv
```

`--follow-up` 可覆盖默认观察窗口；默认取相邻两波计划开放日之间的最短间隔，避免本波窗口跨入下一波开放。

## 分析口径

- **分组固定**：居民按抽签时所属片区与赋予的开始时间归组。实际到哪里上课、是否参加，都不改变其组别；跨区学员不会被计入转入区。
- **分母**：各波抽签片区内基线合资格居民，一人只计一次。
- **主指标**：指定随访窗内至少一次有有效证据的实际出席。有效证据要求回报完整、记有出席，且所记站点当日正式开放（或有已确认的临时借场事实）。
- **未知**：未完整回报且无有效出席证据者记为未知，不计作未出席。报告同时给出"未知计为未出席"至"未知计为出席"的范围。
- **区间**：以抽签片区为不确定性单位估计，居民不作为独立抽样单位。
- **对照**：仅使用同波、同观察窗口内当时尚未分配开放的片区；已开放片区（含事后更正开放期后实际已开放的片区）不得重新充当对照。
- **串扰诊断**：按居民原属片区及当日可达的已开站点，区分本片区提供服务、仅邻区提供服务、均未提供；缺报不等同于未开放，临时借场单列，不混作未开。
- **意向与暴露分离**：意向分配效果按抽签组比较；按实际暴露的描述仅说明执行情况，不称为因果效应。
- **决策**：按 `data/review.json` 的最低增益、允许串扰与缺报上限，以及必须覆盖的片区类型给出继续、延长观察或待补证。可见增益但证据未过门槛时不自动推荐继续；所需片区类型按批次整体在可比试验与对照臂中评估。
- **签批留痕**：已签发建议不可在原编号下覆盖。补报或借场更正后按原抽签组重算，另出引用原记录的新修订；若新证据使既有建议失去依据，受影响且尚未开课的排期转为暂停，只有该批新的审批决定能恢复。
- **材料分层**：审签人常规材料只含汇总；居民级纳入/排除理由仅用于项目组内部分波次比对。

## 数据约定

所有居民、机构、地点与活动均为虚构标识，时间以数据字段的本地日期表示。空字段表示该资料没有登记值，不应据此推断业务事实；具体数据口径以相应字段和 JSON 政策文件为准。资料用于离线分析，不含外部服务或凭据。
